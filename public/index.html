📲 Get Android APK / App

You can install this game directly on your Android phone or generate a standalone .apk file in 1 minute:

1
Direct Mobile Install (PWA):

Open this link on your Android phone in Chrome, tap the 3 dots (⋮) and select "Install app" or "Add to Home screen". It installs instantly with the app icon on your home screen!

2
1-Click Free Signed APK (PWABuilder):

Deploy your code to Render.com (or GitHub Pages), go to pwabuilder.com, enter your live URL, and click "Package for Android" to download a ready-to-install .apk file!

3
Native Android Studio (Capacitor):

Use the included Capacitor configuration to run npx cap build android to generate a native APK with Android Studio.
