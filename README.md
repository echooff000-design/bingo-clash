# 🎮 Arcade Clash - Bingo, Tic Tac Toe & Ludo

A modern, visually stunning **Multi-Game Arcade** built with real-time multiplayer support for **Render.com**, repository setup for **GitHub**, smart **Computer AI** for offline single-player, and ready for **Android APK** generation!

---

## 🌟 Included Games

1. 🎱 **Bingo Clash (5x5 Duel)**:
   - Classic 1–25 grid duel.
   - Shuffle or arrange numbers manually.
   - Strike numbers simultaneously. First to complete 5 lines (B-I-N-G-O) wins!
   - Single Player vs Computer AI or 1v1 Online with Friends.

2. ❌ **Tic Tac Toe Arena (3x3 Duel)**:
   - Neon glowing X & O cells with win-line animations.
   - Smart Minimax AI bot for challenging single-player.
   - Real-time online 1v1 multiplayer with friends.
   - Scoreboard tracking wins, losses, and ties.

3. 🎲 **Ludo Duel (2-Player Fast Track)**:
   - Fast-paced 2-player duel (Red vs Green).
   - 3D animated dice roller with authentic physics/dot styling.
   - Safe spots (⭐ Star tiles), home runways, and capture mechanics (send opponent back to base!).
   - Smart Computer AI bot that evaluates board positions, captures, and home sprints.
   - Real-time 1v1 online multiplayer with friends.

---

## 🚀 Easy Game Switching on Same Link

Players can switch between all 3 games instantly using the top **Arcade Tabs**:
- `🎱 Bingo`
- `❌ Tic Tac Toe`
- `🎲 Ludo`

Shareable room links automatically load the correct game! For example:
- `https://your-app.onrender.com/?game=bingo&room=ABC12`
- `https://your-app.onrender.com/?game=tictactoe&room=DEF34`
- `https://your-app.onrender.com/?game=ludo&room=GHI56`
